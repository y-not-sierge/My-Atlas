# 🌍 My Atlas

A personal, interactive world map. Click anywhere to pin the places you've been,
the places you dream about, and everything in between — right in your browser.

## ✨ Features (v0.1)

- **Interactive world map** — dark-themed, free tiles, no API key required
- **Click to pin** — name a place, add a note
- **Auto-save** — pins persist in your browser via localStorage
- **Sidebar** — your places list; click to fly to a pin, ✕ to delete it
- **Export / Import** — back up your atlas as JSON, restore it anywhere
- **Responsive** — works on desktop and mobile

## 🚀 Getting started

It's a single static file — no build step, no dependencies.

```bash
# Option 1: just open it
open index.html

# Option 2: serve it locally
npx serve .
```
